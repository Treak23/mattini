## The rule as pinned (the session's decisions 1 to 6; R measured)

- Drawn streams: TLM_FLIESSGEWAESSER OBJEKTART 4, VERLAUF 100 or 500, exactly the lines the class
  grid draws as water, in the order `class_grid` reads them (the features as handed over, sorted
  by UUID by `read_tlm`; parts in order; segments in vertex order).
- `flow_code(dx, dy)`: 0 for a zero-length segment; else `1 + round(bearing / 1.5) % 240`,
  `bearing = math.degrees(math.atan2(dx, dy)) % 360.0`. Python's `round` (half to even).
- Cells: 2 m on the area's box (`_Frame(box, 2.0)`): columns = width / 2, rows = depth / 2; texel
  (r, c) centred at E = e_min + 1 + 2c, N = n_max − 1 − 2r.
- Passes: radius 12 m, 11 m, … 1 m; in each pass every non-zero segment's stadium (the class grid's
  `_stadium_spans` arithmetic, distance ≤ r, ties included) painted with its code in segment order,
  a later paint overwriting.
- **R = 12 m, and MARGIN_M raised from 10 to 12 m** (decision 4's rule, measured below).
- Encoding name (my choice, decision 5 asked for one): `"downstream-bearing-1.5deg"`.
- The description's `flow`: `{"cell_m": 2.0, "columns", "encoding", "file":
  "surfaces/<area>-flow.png", "pixels_sha256", "rows", "sha256"}`.
- The config's area: `"flow_cell_m": 2` (an int in the file; `FLOW_CELLS = (2.0,)` accepts int 2 or
  float 2.0, refuses 1 and "2"), `"expected_flow_pixels_sha256"`, `"expected_flow_png_sha256"`
  (single values).
