## The session's decision and how it was followed

Decision 1: as v0.3.1-06 did for 0.3.1 — the version 0.4.0 wherever that brief changed it, nothing
else. v0.3.1-06 (f0d54a5) changed `game/project.godot` line 14, `test_project_settings.gd` line 8,
and `test_release_settings.gd` (header comment, test name, expected value). This brief changes the
same lines and nothing else. Hits before the change, `git grep -n -e '"0\.3\.1"' -e '0_3_1' -e
'^## 0\.3\.1\.' -- game tools pipeline config tests`: exactly five (project.godot:14,
test_project_settings.gd:8, test_release_settings.gd:6, :71, :72); after the change: none. 18 other
tracked files under `game tools pipeline config tests` name 0.3.1 as history (brief ids, "0.3.1's
light") and stay: `git grep -l '0\.3\.1'` there lists 21 files before the change, the three this
brief edits included, and 19 after, since `test_release_settings.gd`'s header keeps naming 0.3.1.

v0.3.1-06 had no pinning folder (the builder edited the two tests). Here the two tests are pinned
whole, re-cut for 0.4.0, so the builder copies them and edits only `project.godot`. The brief's step
1 diffs the live files against the pins first, so a fix-batch edit to either file is caught, not
overwritten.
