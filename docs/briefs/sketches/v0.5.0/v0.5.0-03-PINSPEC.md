## Open questions, with recommendations

1. **The shader's sampler (the next batch of lane G, SH-4).** M4-06 decision 3 declares
   `capture_shadow : hint_default_black, filter_linear, repeat_disable`: a sampler without a
   mipmap filter never reads the chain this batch builds, so the decision takes effect only if the
   look's brief changes it to `filter_linear_mipmap` (or `filter_linear_mipmap_anisotropic`, as the
   photo). Recommendation: amend M4-06 decision 3 in SH-4's brief to `filter_linear_mipmap_anisotropic`
   (the photo's), pin it in its look census, and add its mutation row ("the mask's sampler without
   mipmaps"); the session's distant render is the only evidence that it helps. The loader's no-mask
   fallback (a 1 × 1 L8 texture of 0) needs no mipmaps.
2. **The lift with a mipmapped mask.** The lift is albedo × (1 + (shadow_lift − 1)·m), linear in m,
   so a mip level's average m lifts each pixel by the mean of its texels' lifts before the clip at
   1: the right average where nothing clips. Recommendation: none needed; say it in SH-4's comment.
3. **The PNG that cannot be decoded at all** is a refusal site with a file hint (decision 3) that
   no test reads: Godot's PNG loader prints three engine `ERROR` lines for it (`Condition
   "!success" is true. Returning: ERR_FILE_CORRUPT`, `Condition "err" is true. Returning:
   Ref<Image>()`, `Condition "image.is_null()" is true. Returning: ERR_PARSE_ERROR`), which GUT
   counts as unexpected errors and the gate scans; SurfaceGrid's and PhotoGrid's own decode sites
   are untested for the same reason. Recommendation: leave it (the census forbids a hand-spelled
   hint there, so the only possible miss is a site with no hint at all); an allowlist entry for
   engine text this generic would be refused or too wide.
4. **The hot files.** `complete_world.gd` and `gate_allowlist.txt` are pinned whole. If lane P
   (SH-1, SH-2) or anything else lands a change to either before this batch, the pinned copies are
   stale. Recommendation: the session checks `git diff d522abf origin/main -- game/tests/complete_world.gd tools/gate_allowlist.txt` is
   empty before spawning the builder, and re-cuts the pin otherwise. SH-4 (the loader and the
   look) and SH-5 (the main scene, its own allowlist line) build on this batch's versions.
5. **M4-10's later pin of the release hints** (`docs/briefs/pinning/M4-10/game/tests/test_m4_08_release_hints.gd`)
   has its own `test_capture_mask_missing_or_damaged` with two cases; this brief's has five and
   lives on 0.4.0's file. Recommendation: SH-5 re-cuts nothing in this test for the mask (it is done
   here); only the surroundings' cases stay M4-10's, for the far mountains' release.
6. **`_read` as part of the reader's API** (decision 1): the hints test calls it, as it calls every
   other reader's. Recommendation: accept (pin author's choice, recorded in the brief).
