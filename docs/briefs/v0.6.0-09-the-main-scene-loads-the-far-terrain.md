## Goal

The game the owner starts draws the far terrain around the area (design §3, SPEC §13 rows 58,
59): the main scene reads the manifest's `surroundings` block after the capture mask and builds
it ("Surroundings", at the scene's origin, unturned); the camera's far plane reaches every corner
of it (40 km); the started game prints one more startup line after the shadows' line,
`mattini <v>: surroundings village loaded, 841 x 861 vertices at 50 m, colour 4200 x 4300 at 10
m` for the real village; a missing or refused block opens the error panel with "the far
terrain" and the four commands that build it, everything else still shown; the credits carry
swissALTIRegio's whole source text and the far colour (SWISSIMAGE: the photo's line when the
edition and the attribution agree). The complete test world the main-scene tests and two render
checks build gains a small far terrain, and every RENDER line stays the head's (one control
figure of the trees' check moves, decision 9).
