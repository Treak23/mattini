## Goal

`tools/export.sh` refuses a manifest without the far terrain's block, naming the four commands
that build it, and requires the started Linux build to print the far terrain's startup line after
the shadows' (ten startup lines with the two data packs); the far terrain's files ship in
`mattini.pck` as they are. `.github/workflows/release.yml` downloads the far terrain's two inputs
and runs its two steps before the manifest, so a Release carries it. docs/RELEASE.md §C names the
downloads, the steps, the far terrain's designed values, where its files ship, the ten startup
lines, and names 0.6.0's manifest pair, measured by the session's integration rehearsal:
328'184 bytes, `a5a3ef65400a4535791ee8b727375036798d7a4a3379b7400f4c9716ce344734`.
