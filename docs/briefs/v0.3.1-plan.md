## What 0.3.1 delivers

The items of the owner's 0.3.0 test (`docs/feedback/INBOX.md`):

- **The river (FB-003):** the photo's own colour (× 0.9 instead of × 0.6), less mirror
  (roughness 0.3 instead of 0.05), smaller ripples drifting apart at 0.8 m/s, the bank eased
  over 1 m instead of a 0.2 m stepped edge.
- **The frame cap, the log and the edges (FB-007, FB-006, FB-004):** at most 60 frames a second,
  15 while the pause screen is open; every log line written when it is printed; 4× MSAA.
- **A missing data pack named (FB-005):** the log, and in an exported build the red error panel,
  name the missing pack, its folder and what it holds; every reader's file message in a release
  says to download the release folder again; `tools/export.sh` refuses a release whose packs are
  not exactly the ones the game expects.

Not in it: exposure (stays 0.54 until the moving sun, the owner's 1b), the moving sun, the softened
photo shadows, the far mountains.
