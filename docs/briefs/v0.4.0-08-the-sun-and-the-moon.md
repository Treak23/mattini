## Goal

The game the owner starts runs on Zermatt's clock and sky. The clock, `time_unix`, starts at the
photo's moment (6 September 2023, 13:40 CEST) and runs at 1×, standing still while the pause
screen is open. Every frame the sun and the moon stand where SkyClock (v0.4.0-04) puts them for
the clock's time at the manifest's `sky` block, read by a new reader, SkySite, and turned to the
scene through the world config; the sky rig (v0.4.0-05, -06) lights the scene from them, with the
physical sky, the exposure by day and night and the stars. M3's fixed sun (183°, 52°), its
procedural sky and its exposure 0.54 are gone. Without a sky block the sun stands still at a
labelled placeholder and the panel says why; a refused manifest names the sky too. The pause
screen's credits gain "Sky": the sources of the sun's and the moon's formulas and, with the stars,
the Hipparcos credit. Nothing else changes: the time keys, the clock label and the export are
v0.4.0-09's.

Production code is `main` after v0.4.0-07. The pin author rehearsed this brief in a clone of the
session's `main` with v0.4.0-01 to -07's pins and throwaway implementations merged in
(2026-10-27): the pins red on that code, green on a throwaway implementation, the full gate with
its render step, and all twenty-one mutation rows both ways. Every number marked "rehearsal" was
measured there.
The pin author's record is `docs/briefs/sketches/v0.4.0/v0.4.0-08-PINSPEC.md`, committed by the

- The base, once, before you copy the pins: the standard gate at the head you started from,
  foreground; record in Findings pytest's passed and deselected, GUT's Scripts, Tests and Asserts,
  and the three RENDER lines (rehearsal on the merged 01-07 tree: 2360 passed, 5 deselected;
  57 / 347 / 16148):
  ```bash

  ```
- Import once in a fresh worktree, and again after adding `sky_site.gd` (its `class_name` enters
  the class cache only then, H9):
  ```bash
  godot --headless --path game --import
  ```
- The pinned tests (call it PIN-GUT), from the worktree's root (no `-gdir`: with it GUT runs every
  script):
  ```bash
  godot --headless --path game -s addons/gut/gut_cmdln.gd -gtest=res://tests/test_m4_10_sky_site.gd -gtest=res://tests/test_main_scene_light.gd -gtest=res://tests/test_m4_10_refusals.gd -gtest=res://tests/test_main_scene_refusals.gd -gtest=res://tests/test_scene_placement.gd -gtest=res://tests/test_main_scene_data.gd -gtest=res://tests/test_main_scene.gd -gtest=res://tests/test_pause_cap_and_pack_panel.gd -gexit -gconfig=
  ```
- Byte identity (prints nothing and exits 0):
  ```bash
  (cd docs/briefs/pinning/v0.4.0-08 && find . -type f -print0 | xargs -0 -I{} cmp {} "$OLDPWD/{}")
  ```
- Parse checks, exit 0 each (H2):
  ```bash
  godot --headless --path game --check-only -s res://scripts/main.gd
  godot --headless --path game --check-only -s res://scripts/sky/sky_site.gd
  ```
- Commit: `tools/gate.sh > gate.log && git commit …`; subjects end with `(v0.4.0-08)`, e.g.
  `feat: the sun and the moon on the game's clock, SkySite and the sky's credits (v0.4.0-08)`.
  Stage everything first (`git add`): `pipeline/tests/test_repo_tracked.py` fails on a file on disk
  that is not in git's index (the new scripts and their `.uid` files). Push:
  `git pull --rebase origin main`, the gate again if the rebase brought commits in, `git push origin HEAD:main`.

The first commit holds the nine pinned copies and the production files together (the pins are red
without the change, so they cannot be committed alone). Then the brief's Findings and Status, each
commit chained to the gate and pushed.
