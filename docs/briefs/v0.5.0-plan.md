## The go's three lines

- **The helpers' model:** Sonnet for builders and fixers; reviewers, provers and verifiers on the session's model.
- **The budget:** two days of **wall time** however many builders run (the owner, 2026-10-29), about half a week's
  allowance; the deferred items of question A fill the spare builder capacity.
- **The lane count:** 2, in the session's container (WORKFLOW §Lanes as amended 2026-10-29).

## What 0.5.0 delivers

- **The softened photo shadows (FB-004 item 3; SPEC §13 rows 41, 47):** a capture-time shadow mask, where the photo
  lay in shadow when it was flown (the flight's sun ray-cast on swissSURFACE3D, 0.5 m), lifts the photo inside it
  (G = 3, linear light, clipped at 1) so the moving sun's shadows read and the photo's do not darken a second time.
  The mask is mipmapped like the photo (the owner's "3a": the integration rehearsal's distant software render, with
  mipmaps against without, measured the speckle beyond 350 m 23 to 28 % lower and the frame-to-frame flicker 6 to
  7.5 % lower).
- **Delivery through GitHub Releases (the owner's "1a"):** `.github/workflows/release.yml` builds the release on a
  GitHub runner from the pinned inputs and attaches a Windows zip, a Linux tar and `SHA256SUMS` to a draft Release
  the owner publishes; `dist` stays as the rollback record of 0.1.0 to 0.3.1. 0.4.0 is not delivered on its own
  (the owner's "2c").
- **The trees' haze (FB-004 item 5, variant V2)**, **the clock's note outside 2020 to 2035**, **a RENDER check of the
  river's direction**, and four residue groups, tests and messages only (the owner's "question A OK").
