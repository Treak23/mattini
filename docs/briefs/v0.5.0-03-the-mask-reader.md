## Goal

The game can read the capture-shadow mask, the 0.5 m L8 PNG of where the 2023 photo lay in shadow
when it was flown (brief M4-03's file, written by the pipeline's `shadows` step). A new reader,
`CaptureShadowGrid` (`game/scripts/terrain/shadow_grid.gd`), reads the manifest's `shadows` block
and its PNG, refuses every problem with one error naming the manifest (Hard Rule 2), places the
mask's rectangle through the world config, and holds the mask as an L8 `ImageTexture` with a full
mip chain, as the photo's texture has one, plus `value_at(x, z)`, the texel's byte at a local point.
Its file messages end with `ReleaseBuild.file_hint`, so an exported build tells the player to
download the release folder again. The complete test world (`complete_world.gd`) carries the
shared shadows fixture's mask at a box of its own, so later batches (the loader and the shader,
the main scene) and the render step can read it. Nothing reads the mask in the game yet: the
loader and the shader are the next batch of lane G, the main scene's wiring a later one; the owner
sees nothing new.

Production code is `main` at the head you start from (rehearsed at `d522abf`). The pin author
rehearsed this brief in a clone of it (2026-10-29): the pins red against a stub of the API, green
on a throwaway reader, the full gate with its render step, and all 23 mutation rows. Every number
marked "rehearsal" was measured there. The pin author's record is
`docs/briefs/sketches/v0.5.0/v0.5.0-03-PINSPEC.md`, committed by the session; you do not need it.

## Decisions already made

"M4-06 decision N" and "M4-10 decision N" are those briefs' decisions, quoted here where they bind

1. **The reader, `CaptureShadowGrid`** (M4-06 decision 1; SPEC §13 row 41;
   `game/scripts/terrain/shadow_grid.gd`, `class_name CaptureShadowGrid`, `extends RefCounted`).
   - **Constructor:** `static func from_manifest(path: String, world: WorldConfig) ->
     CaptureShadowGrid`, null after each refusal, each one exactly one
     `push_error("CaptureShadowGrid: <path>: <problem>")`.
   - **`func _read(path: String, world: WorldConfig) -> String`** does all the reading and returns
     the problem, or "" when the block is read; `from_manifest` calls it on a new object and
     push_errors what it returns. This is every reader's shape (PhotoGrid, SurfaceGrid), and the
     pinned `test_m4_08_release_hints.gd` calls `CaptureShadowGrid.new()` then `_read(path, world)`
     to see the message without an ERROR line (pin author; accepted by the session 2026-10-29).
   - **Properties:** `area` (String), `cell_m` (0.5), `columns`, `rows` (int), `x0`, `z0`,
     `width_m`, `depth_m` (float), `dataset` (String), `editions` (PackedStringArray),
     `attribution` (String), `texture` (ImageTexture). `rect() -> Vector4` is (x0, z0, width_m,
     depth_m). `value_at(x: float, z: float) -> int` is the texel's byte (0 or 255) at column
     floor((x − x0) / cell_m), row floor((z − z0) / cell_m), and −1 outside the half-open rectangle
     (its west and north edges in, its east and south edges out). Keeping the sun's two numbers is
     allowed; nothing reads them.
   - **Placement:** texel (c, r) is the 0.5 m square whose north-west corner lies 0.5·c m east and
     0.5·r m south of the box's north-west corner, which is `world.to_local(e_min, n_max,
     world.height_offset)`: x0 and z0 come from that call, never from subtracting an origin here
     (Hard Rule 4); width_m = columns × 0.5, depth_m = rows × 0.5. Image row 0 is the north edge.
   - **The block** is the step's description as M4-03 writes it (M4-03 decision 7), which the
     manifest carries under `shadows`: exactly the keys area, cell_m, columns, file, format,
     lv95_box, pixels_sha256, rows, sha256, source, sun, world_sha256; `source` exactly
     {attribution, collection, dataset, editions, entry_sha256}; `sun` exactly {azimuth_grid_deg,
     elevation_deg, note}; `lv95_box` exactly {e_max, e_min, n_max, n_min}.
   - **It refuses**, every compare typed (`ManifestValue.differs`, brain.md H26: a number where a
     text belongs is refused, never a runtime error that lets the block through):
     a missing or null block (naming `python -m mattini download surface`, then `python -m mattini
     shadows`); another world (`world_sha256` against the manifest's, naming `python -m mattini
     shadows`); a WorldConfig not read from this manifest (its origin's east or north, or its
     height offset, differs: each compared on its own; the pins shift the east and the north);
     other axes than the owner's (the message names "axes"); a key set that is not exact (the
     message lists the keys found); `format` not `png-l8`; `cell_m` not 0.5; `columns` or `rows`
     not a whole number of at least 1; a digest not 64 hex digits; `source.dataset` not
     `swisssurface3d`; `editions` not a non-empty list of texts; a sun value not a finite number;
     the box off columns × 0.5 and rows × 0.5 by more than 1 mm, its width and its depth each (the
     message names "columns"; the pins make it 1 m too narrow and 1 m too deep); a `file` that is
     not a plain relative path inside the manifest's folder (the message names "file"; the pins
     give a path leaving the folder and an absolute path to the fixture's own PNG); then, in this order, the PNG missing (checked before any read), its SHA-256 not
     `sha256` (checked before decoding), a decode that fails or is not L8 of columns × rows, and
     decoded bytes whose SHA-256 is not `pixels_sha256`. Each message names the field it refuses
     (the pinned tests look for: `format`, `cell_m`, `columns`, `rows`, `pixels_sha256`, `dataset`,
     `editions`, `sun`, `source`, `axes`, `file`, `SHA-256`, `L8`, the PNG's file name; and
     `test_m4_08_release_hints.gd` for `<the PNG's file name> is missing` (`fixture.png is
     missing`) and `decodes to <w> × <h>` (`decodes to 8 × 8`, with U+00D7 MULTIPLICATION SIGN,
     not the letter x)).
   - **Decided but not pinned** (the release's checkers, 2026-10-30; for the batch gate's mutation
     prover and `test_v0_5_0_03_gaps.gd`): a sun value not a finite number (NaN or infinity) and
     `sun.note` not a text; an extra or missing key in `lv95_box` and in `sun` (only `source`'s
     extra key and the top level's are pinned) and a box value not a finite number; `editions`
     empty or holding a non-text or an empty text (only editions as a text is pinned);
     `attribution`, `collection` and `entry_sha256` not texts; `area` not a name; a `res://` path
     as `file`; the height offset compare of the WorldConfig guard.
2. **The texture has mipmaps** (the session's decision, 2026-10-29, on the owner's 3a; amends
   M4-06 decision 1, which said "L8, no mipmaps"). After every check has passed, the decoded L8
   image gets `image.generate_mipmaps()` and the texture is
   `ImageTexture.create_from_image(image)`: a full chain down to 1 × 1, every level L8, level 0
   the decoded PNG byte for byte. Why: the photo, 0.2 m, is mipmapped and sampled
   `filter_linear_mipmap_anisotropic` (`photo_grid.gd`, `generate_mipmaps()` in `_make_texture`); a
   0.5 m binary mask without mipmaps under it would alias in the distance (the session's estimate:
   beyond about 350 m). `value_at` reads level 0, the decoded bytes (keep them before the mipmaps
   are made, or read the first columns × rows bytes). Rehearsal, two ways: the village's 4000 ×
   6000 mask is 24'000'000 bytes at level 0 and 31'999'757 with its 12 levels below it (Godot's
   `Image.get_data().size()` after `generate_mipmaps()`; a sum of max(1, 4000 >> i) × max(1, 6000
   >> i) over i = 0 to 12): 22.9 MiB without, 30.5 MiB with. Reading a synthetic mask of that size
   as the throwaway does, headless in the container: PNG SHA-256, decode 0.09 s, the pixels'
   SHA-256 0.10 s, mipmaps 0.012 s, about 0.2 s in all (three runs; not the owner's PC, and no GPU
   upload headless). Which sampler reads the mipmaps is the shader's, the next batch's: not yours.
