# BLOCKED — questions from builders

Plain text, newest first. A builder that hits genuine ambiguity writes its question here,
marks its brief `Status: BLOCKED`, and stops — it never invents the answer. The release
session answers by a commit (DESIGN.md §How the session decides), never by a message.
Check `docs/history/RULINGS.md` BEFORE filing: a question it already answers is answered,
not filed. Answered blocks move to `docs/history/blocked/` (DESIGN.md standing rule 3).
