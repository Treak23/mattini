## Decisions already made

1. **The credits (S-01, K1; P1).** In `tools/release_notes.md` the Software paragraph names exactly what ships and what the
   pause screen shows: Godot Engine, Terrain3D and godot-cpp (compiled into Terrain3D's library), MIT; GUT is not named (it is
   a test addon, not shipped). The Sky credits the pause screen shows are carried word for word: the text of `SUN_NOTE` and
   `MOON_NOTE`, under a "Sky:" heading beside the stars' credit. A new test (a new file
   `pipeline/tests/test_v0_5_0_15_notes.py`) reads `game/scripts/main.gd`, extracts the two notes' string text (the
   concatenated literals of each `const … := (…)`), and requires each to appear in the template verbatim; it requires
   "godot-cpp" and requires that "GUT" does not appear. It fails on today's template.
2. **The rollback (S-02, K2; P1, the session's grade).** The rollback paragraph says: the rollback is the previous version's
   Release; for 0.5.0, the first version delivered as a Release, it is the `dist` branch's folder `mattini-0.3.1/`
   (https://github.com/Treak23/mattini/tree/dist/mattini-0.3.1), because 0.4.0 was never delivered. A later release's session
   rewrites this line (it is the session's words thereafter; RELEASE.md §E will say so). The new test requires the template
   to name `mattini-0.3.1/` and the dist tree URL, and not to say "the Release of the version before this one" alone.
3. **The checksum line (correctness N3, owner N1).** The instruction becomes `sha256sum -c --ignore-missing SHA256SUMS`, so a
   player who downloaded one platform's archive can check it; the test requires `--ignore-missing`.
4. **`tools/export.sh`'s header (S-06, K4; Hard Rule 2).** Narrow the words, do not change the behaviour: the line
   "export: build/ is unfinished, do not ship it" ends every refusal `fail()` makes once step 4 has begun; a command that
   dies on its own under `set -e` (a file that cannot be removed, a full disk) ends the export with its own error and exit 1
   and no such line, and `build/` is then unfinished too. One test in the new gaps file greps the header for both sentences.
   (Not taken: an EXIT trap that prints the line; the skeptics found no shipping harm: `release.yml` and RELEASE.md copy only
   after exit 0.)
5. **The flow check's blind spots (S-05, K3, R1-CD-01; Hard Rule 2).** `render_flow.gd`'s "Proves … not …" list and
   `tools/gate.sh`'s header both say: the check does not see where the flow is read (a north-south shift that keeps the
   windows on band rows passes, and so does an east-west shift within the bands); its data cannot see ripple map b reversed
   alone (only the 0.60 correlation floor) nor a dropped validity factor (every test texel has B = 255). Words only; the
   check's numbers do not move. `test_v0_5_0_09_gaps.py` (which reads the gate header's north-south sentence) stays green.
6. **`render_lift.gd`'s header (S-08, R1-CD-03).** The sentence saying the main scene does not read the mask is false since
   v0.5.0-05: say that the main scene hands the mask from 05 on and that this script builds its own terrain on purpose.
7. **`star_image`'s comment (correctness N1).** It said an out-of-range right ascension "was drawn at a wrong column"; the
   code drew it at the equivalent column. Say what the guard prevents: a table line outside the catalogue's range is refused
   by name, not silently wrapped.
8. **Pinned files edited.** `render_flow.gd` (v0.5.0-09's pin), `render_lift.gd` (v0.5.0-04's) and `tools/release_notes.md`
   (v0.5.0-06's, not pinned) are live copies of DONE briefs: after DONE the live copies may evolve (WORKFLOW §Brief
   lifecycle); 04's and 09's byte-identity commands will then report these files as superseded, which this brief records.
